# Security policy

## Supported versions

Only the latest release gets fixes. Update from **Settings › About** or
download it from [Releases](https://github.com/Imsteven0/Hyperland-windows/releases/latest).

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Imsteven0/Hyperland-windows/security/advisories/new)
with the affected version, what an attacker could do, and steps to reproduce.

You'll get an answer within a week. Once a fix is released, the advisory is
published crediting you (unless you prefer otherwise).
